# Full Sound Garage Bookings

vamos criar um sistema de agendamento simples (sem muitas funções desnecessárias). O cliente escolhe o serviço que a Full Sound GARAGE oferece (são: Insulfilme, envelopamento, Som e LEDs), vê qual horário e dias tem disponíveis, o pagamento é no local (não terá sistema de pagamentos), loga com Google quando clicar em “Agendar”, mas essa parte pode deixar por último porque vamos usar Firebase e preciso configurar ainda, porém pode deixar todo esquema pronto para receber as keys e as coisas do firebase (apenas não exija ainda nenhuma autenticação). No painel administrativo, o dono tem que ter o controle de agendamentos, para organizar quais dias tem veículos, quais veículos são (o cliente tem que informar: marca, modelo e ano do carro), quem são os clientes e ter uma função de “reserva confirmada” para o cliente após ele confirmar. As cores de todo sistema tem que ser igual da logo que anexei, laranja e branco e alguns detalhes pretos. Sugere algo a mais?
